# MotionToggle/

L'interruttore della modalità di movimento, nel pannello delle preferenze, che si apre dall'ultimo bottone del menu a pillola (`../Preferences/`).

| File | Cosa fa |
|---|---|
| `MotionToggle.tsx` | tre bottoni (Off, On, X-ray) in un `radiogroup` accessibile; al clic cambiano la modalità con `useMotionMode` |
| `MotionToggle.module.css` | pillola chiara in trasparenza sul fondo scuro del pannello, bottone attivo corallo; nessuna posizione sua, il posto glielo dà la riga del pannello delle preferenze |
