# MotionToggle/

L'interruttore della modalità di movimento, in basso a destra.

| File | Cosa fa |
|---|---|
| `MotionToggle.tsx` | tre bottoni (Off, On, X-ray) in un `radiogroup` accessibile; al clic cambiano la modalità con `useMotionMode` |
| `MotionToggle.module.css` | pillola scura semitrasparente, bottone attivo corallo; sul telefono sale sopra il menu |
